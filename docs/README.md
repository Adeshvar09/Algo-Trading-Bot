# Project Documentation

## Architecture Overview
The project follows a strictly modular enterprise full-stack architecture:

- **`frontend/`**: React + Vite application with modular UI components, layout elements, feedback states, feature modules, hooks, context, and custom services.
- **`backend/`**: Node.js + Express TypeScript server built around an MVC pattern with config, controllers, routes, services, models, middleware, validators, custom error handling, and database layer.
- **`database/`**: PostgreSQL schema definitions and synthetic seed data.
- **`tests/`**: Suite of automated test runners.
- **`docs/`**: Technical project documentation.
